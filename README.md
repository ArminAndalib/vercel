# Armin Andalib — Portfolio

پورتفولیوی شخصی با استایل ترمینال.

## دیپلوی روی Vercel (خیلی ساده)

### روش ۱ — مستقیم از فایل‌ها
1. برو به [vercel.com](https://vercel.com) و لاگین کن (با GitHub بهتره)
2. New Project → Upload
3. پوشه `armin-portfolio` رو آپلود کن
4. Deploy

### روش ۲ — با GitHub (پیشنهادی)
```bash
cd armin-portfolio
git init
git add .
git commit -m "initial portfolio"
# بعد روی GitHub یه ریپو بساز و push کن
# بعد توی Vercel ریپو رو ایمپورت کن
```

سایت روی آدرسی مثل `armin-andalib.vercel.app` بالا میاد.

## سفارشی‌سازی
- متن‌ها رو توی `index.html` ویرایش کن
- رنگ‌ها توی `styles.css` بخش `:root`
